# OnlineAlkansya
Expenses &amp; Income Tracker 

An Expenses & Income Tracker to help you manage your money and grow your savings.
This is a **frontend-only** project: no backend, no database, no login. All data is stored in your browser using `localStorage`.

## Features

- Add income and expense transactions
- Categorize transactions (Food, Transport, Bills, Salary, Allowance, etc.)
- View current balance, total income, and total expenses
- Set a savings goal and track your progress
- Edit and delete transactions
- Filter transactions by date, category, or type
- Responsive design for mobile and desktop
- Data persists after refresh (saved in localStorage)

## Tech Stack

- HTML
- CSS
- JavaScript
